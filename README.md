# vetles-roetter
Gulrot-tracker nam nam

## Kjør
Du trenger (go)[https://go.dev/]

```bash
go run .
```

## Utvikling
Du må lage en `.env` (Kopier `.env.example` og endre verdiene)
Anbefaler å bruke (wgo)[https://github.com/bokwoon95/wgo]:

```bash
wgo run .
```

## Bygg
```bash
go build .
```

BOOM
